# Read this first: where each piece comes from

Jeromie Beasley, 3 November 2026.

Good math does not hurt other good math. It only does harm when it is connected wrong. A correct standard result attached to my framework as if it were my result is the main way an error can spread through this work without anyone noticing. This note exists so that never happens unknowingly.

## The rule

Every section here is tagged with where its idea and its method come from. Only sections whose source is my own work go into a paper under my name as findings. Everything else goes in as a labelled comparison, or it stays out.

| Tag | Meaning | How it may be used |
| :-- | :-- | :-- |
| **MINE** | The idea and the method come from my papers (VOTKP, Matter at a Scale, the cone paper) and are checked against their own numbers. | As findings. |
| **MINE ON A TEST BED** | My idea, tested on a standard model chosen as a test bed. | As findings about that model only, never as a general law, until it is tested on a second, different model. |
| **IMPORTED** | A standard or outside method (a reviewer, the literature, textbook physics) written in my coordinate. | As a labelled comparison or a reproduction note, never as my result. |

## Checks before anything leaves this folder

1. Open my own paper first and test my version of the idea, not a rebuilt one.
2. Write the kill condition before the run.
3. Tag the section here before its README row is written.
4. Never feed an IMPORTED section into a MINE section's argument without saying so where it is used.
5. Work from other chats is untrusted until it has been rechecked against my own papers. That includes the ledger runs of 3 Nov 2026, between about 4:25 and 5:45 am.
