## Sections, definitions, results
1. Gram. H_N = B_N* B_N / Tr(B_N* B_N): PSD, trace one; leading eigenprojector = dominant right singular projector of B_N; "not the spectrum of a single transport step."
- Theorem 1 [T] (gapped Gram limit selects a line): H_N -> H in operator norm, H has simple top eigenvalue lambda1 with gap delta = lambda1 - lambda2 > 0, top projector Q. Then Q_N eventually unique and converges; with eta_N = ||H_N - H||: 1 - Tr(Q_N Q) <= 2 eta_N / delta. Proof by variational principle; top gap of H_N >= delta - 2 eta_N; ||Q_N - Q||_F^2 = 2(1-|u*v_N|^2). No trace normalization required. "The theorem is sufficient; a moving Gram matrix can also have a fixed top projector without converging as a whole."
- Theorem 2 [T] (strict dominance, finite error): B_N/s_N = u_N a* + E_N, ||u_N||=1, a != 0, ||E_N|| -> 0. Then dominant right singular projector -> aa*/||a||^2. eps_N = 2||a|| ||E_N|| + ||E_N||^2; when eps_N < ||a||^2/2, 1 - Tr(Q_N aa*/||a||^2) <= 2 eps_N/||a||^2.
- Order-2 corollary [T]+[C]: with independent real solution states f_N=(f_N,f_{N-1})^T, d_N, ||f_N||/||d_N|| -> 0, dominant seed functional annihilates (f_0,f_{-1})^T, representing line span(-f_{-1}, f_0)^T; for continued fraction with Pincherle value K=-f_0/f_{-1}, f_{-1} != 0, selected line has slope K [1, Prop 1]. "does not replace the arithmetic proof identifying the minimal solution."
- Tied growth, three outcomes [T]+[V] (A_N = B_{N+1}B_N^{-1}): (1) B_N = 2^N diag(2,1): comparable growth yet H_N = diag(4,1)/5, Q_N = e1 e1^T for all N (selected line without modal separation); (2) B_N = 2^N diag(2,1) R(N pi/4): Gram top line rotates periodically, no limit, singular values separated in ratio 2; (3) B_N = 2^N I: entire plane top singular space (unresolved block). "A growth tie alone establishes none of them."
2. Pairing.
- Theorem 3 [T]+[C] (dual conservation, finite readout error): x_{n+1}=A_n x_n, l_{n+1}=A_n^{-T} l_n => l^T_{n+1}x_{n+1} = l_n^T x_n; invariant under x'=S^{-1}x, l'=S^T l. Readout: fixed row functionals p,q, qx != 0, K=px/(qx); y=c(x+r), c != 0, ||q|| ||r|| < |qx| => |py/qy - K| <= ||p - Kq|| ||r|| / (|qx| - ||q|| ||r||). "Conservation alone does not identify a number." Two costs: selection error r and readout sensitivity through qx.
- Theorem 4 [T]+[C] (coboundaries): T(n)U(n+1)=U(n)C(n) => T(0)...T(N-1) = U(0)[C(0)...C(N-1)]U(N)^{-1} (official coboundary identity [1, Cor 2]). Singular directions and Frobenius stress computed with a fixed coordinate Euclidean norm are "not invariant under arbitrary rational gauges". "A varying frame along a single path does not require nonzero curvature. Curvature is tested by a two-parameter connection, not inferred from a mismatch between frames at two depths."

5. Proposition 7 [T]+[V] rank-one stress: B=uv*, ||u||=||v||=1, S(B) = (1/2)||BB* - B*B||_F^2 = 1 - |u*v|^2. Tensor composition: 1 - S(B (x) C) = (1-S(B))(1-S(C)).
