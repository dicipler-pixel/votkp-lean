# Can the eight-rung profile travel to another period?

Jeromie Beasley's Codex table, 23 November 2026. This protocol follows PT-SHAPES-01B and the fair-baseline review. The original publications already inspected these elements. The following reference-panel comparison is prospective for this analysis, retrospective for the atomic data.

**Inputs.** Use the pinned October archive for the first nine energies, with ion charges exactly 0 through 8. Use the table v2 for symbols and displayed column positions. Exclude La–Lu and Ac–Lr from both reference and query pools: their detached-row horizontal coordinates are a layout convention. List the out-of-range elements, missing-input exclusions, and measured, semiempirical and theory input counts. Restrict the reference set to F–At. With a measured-only analysis, require all nine input thresholds of both elements to be experimental; if the pool is empty, report that explicitly.

**Primary test.** For each reference element in turn, exclude its entire period from the candidate set. Find the nearest remaining element by the fixed PT-SHAPES-01B simplex distance and by Euclidean distance on the same eight natural-log ratios. Score exact long-column recovery. Report hit counts, the paired discordant queries, and any nearest-distance tie at relative tolerance $10^{-12}$ and absolute tolerance $10^{-14}$. A tied query with differing labels is unresolved. Report impossible labels (no member of the query's column in the reference pool) separately, without quietly dropping them.

**Extension.** Freeze the reference set at F–At, then use each eligible element from Rn through Og as a query. The held-back elements cannot nominate one another. List each prediction, both nearest neighbours and input grades. Also report the fraction that can be scored with exclusively experimental queries and references. This tests transfer to the chosen reference panel; a known group assigned from a partly modeled threshold ladder is not a newly predicted element.

**Decision.** Count the simplex advantage as having transferred on a panel only if its paired wins exceed its losses and the exact two-sided sign test on the discordant queries has $p<0.05$. This is a descriptive hurdle; correlations within chemical families preclude an independent-sample population interpretation. Run those two comparisons as specified even if the first fails. Report the other outcomes, including zero discordants and equal scores. No adjustment of the distance, period boundaries, or charge window after reading the result. This score does not involve the value of the loop wall.
