7. FINDINGS (from the code; not run)
==========================================================================

F1  The I/J/K z-label text is stale after construction under at(t).
    updateBalls rebuilds the labels only when BALLS.t > 0.5 (L619). BALLS.t grows only by dt (L619).
    at(t) passes dt = 0 (L702 update(0); L715 reduced path also uses dt = 0 for applyEmph), so the rebuild
    never fires after the first update. The labels keep the z values from construction (3.00, 5.00, 7.00 under hold)
    while the orbs move. The positions do follow.

F2  The reduced at(t) path skips some updaters.
    L715: if drive is 'hold' and layers rays = 0, at() runs only updateStack, updateLoop, updateRim, applyEmph.
    It does not run updatePress (RECP rings, PRSP arrows) or updateHyp (HYPX, HYPY), and it does not run
    updateFaces, updateCross, updateBalls, updateTree, updateRays.
    Under 'hold' the tree, faces, cross, balls and rays depend only on r or chi, so skipping them is harmless
    except for rays, which are hidden on this path. But RECP and the hyp dots depend on ST, which
    advances, so they freeze on this path. Also S is not re-fed (L715); under 'hold' that is harmless
    because S does not change except S.chi and S.tau.
    Triggered by layers({rays: 0}) together with the 'hold' drive.

F3  The wrapper forces drive 'hold' (L512), so the L.DEF value 'breathe' (LH L357) never applies unless
    the page passes options.drive.

F4  Silent capacity limits. segPush (L529) and ptPush (L533) return without error when the buffer is full.
    Capacities: RAYL 60000 vertices, RAYP 9000, HITP 800, STKP 6000, PRSP 2400, RECP 864, HYPX 1200,
    HYPY 1200, RIMP 1600, ORBP 48 (40 used), CARRY 220 (ring buffer, wraps). Whether any buffer fills at a
    given setting was not tested.

F5  The CARRY trail gets one point per update() or reduced at() call (L677), not per unit of tau.
    Repeated at() calls at the same t add points.

F6  HYP.shown (L513) is never exposed. The hyp layer can only be switched off with layers({hyp: 0}).

F7  The LH-MATH self-test (L447-481) and the MM-MATH block are not drawn and are not part of the page.
