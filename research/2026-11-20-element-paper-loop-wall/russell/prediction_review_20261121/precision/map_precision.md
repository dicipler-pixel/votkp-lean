# How accurately must the return map be measured?
Codex for Jeromie Beasley, November 21, 2026. This addresses the engineered core-opening comparison. Fix the same two real coordinate calibrations on the input and output. For an inferred real 2×2 map M, write M=tI+[[u,v+w],[v−w,−u]]. Put r=√(u²+v²). The sign of its eigenvalue discriminant is the sign of r−|w| whenever r+|w|>0, since Δ=4(r²−w²). Its Frobenius distance to the set of real repeated-eigenvalue matrices is exactly |r−|w||. Indeed squared distance in these four coordinates is 2(dt²+du²+dv²+dw²). Project onto r'=|w'| with t fixed, radial direction preserved and w's sign preserved, setting r'=|w'|=(r+|w|)/2. The reverse triangle inequality gives the matching lower bound. Continuity covers zero components.

A common but insufficient measurement specification is a tolerance on the trace alone. Without enforcing determinant one, even a perturbation that keeps the trace exactly constant can take the real map across the repeated-eigenvalue set. The two-port response measured with separately prepared basis inputs gives access to all four entries. For equal faces 35/6 the exact eigenvalues are −441/400 and −400/441. The trace sits 0.0095294785 below −2; the nearest real perturbation changing spectral type has Frobenius distance only 0.0011917162 in the stated coordinates. If all four measured entry errors are bounded by m, Frobenius error is at most 2m. Thus m < 0.0005958580 suffices for that setting, and m < 0.0003921053 for Be/Rb. These are conservative absolute entry tolerances using no error covariance. Check trace negativity and determinant positivity separately before interpreting as a negative branch or normalized round trip. Reconstructed covariance ellipsoids can improve the budget. Deliberate changes of coordinate units change these numerical tolerances.
