# Review of the nine-view Periodic Table of Elemental Peels v1

Reviewed the original HTML, data and builder in an isolated checkout of [6068b3f](https://github.com/dicipler-pixel/votkp-lean/tree/6068b3f634817f4a9b864351466388726233a49e/research/2026-11-20-element-paper-loop-wall/ptable). The versioned original was preserved. This review covers that snapshot.

**Recomputed data.** Independently read the archived ionization energies (gzip SHA-256 `75e67478d9a22ef85fa2d3f6ac36ad2860c6f8f62215127c558438a2cb53f62c`) and the versioned mixer's affinity input. At the builder's seven-significant-digit output precision, all 3,655 energies, all 3,570 ordinary ratios, squared reflections, squared-energy sums/differences and flags, all 305 named core openings, all 85 endpoint logs and all 65 sets of affinity fields agree. All 177 element-specific theorem links identify the expected declaration at the stated line in this checkout. Pin their URLs if keeping v1 as a historical table since its links follow the moving branch. The displayed optical sample has 35 metal means above ½ and six nonmetal means below ½. This last count is from the committed optical summaries. The underlying wavelength samples were external to the builder's checkout.

**What to change in a successor**

| View | What the pinned data and code actually establish | Suggested edit |
|---|---|---|
| Standard / signature / octave / detail | An absent EA entry means no central value in this 65-row ledger. Ca, Sr and Ba are all marked bound/outside in the same file while the explanatory prose includes them among alkaline earths without stable anions. The extended ledger has an experimental lower bound for Sm, estimate-grade Dy/Tm and a preliminary observation for Po. The heavy-anion test card itself acknowledges Po. | Say “no numerical rung in this edition,” surface evidence grades, reserve “unbound” for a sourced physical conclusion, remove family-wide example. |
| Russell octaves | P→S, As→Se and Sb→Te go outside→inside from 3− to 2−. O→F changes from 2− to 1−; O is outside. Bi is outside, Po has no numeric rung here, At is inside. | Report three matches, one later turn, one unresolved in this edition. State provisional Po separately. |
| Stone / tests / drawer | The data compute χ/η = 1/Γ and the descriptor χ²/(2η). At the wall these give √2 and η under the definitions printed. The neutral-centered quadratic matching both end energies is E(x)−E(0)=−χx+ηx², E(−1)−E(0)=I and E(1)−E(0)=−A. Its minimizer on the real line is χ/(2η) = 1/√2 at the wall and gain χ²/(4η) = η/2. | Name the hardness convention and descriptor every time. Reserve “electrons transferred” for a specified donor/acceptor experiment or energy model. The two numerical descriptors can coexist under explicit conventions. |
| 3D chain | Bright area / outline area actually equals max(Γ²,0.0009). The renderer forces the radius to at least 0.03 of the outline for 1,562 of 3,570 links. At k=82 for At the displayed area is 15.61 times Γ². | Use true radii with a separate visibility halo or explain the floor. The ladder's numerical Γ² values passed. |
| Disk | Outside lie eight of 3,570 ordinary dots and 53 of 65 anion rings, totaling 61 of 3,635 data marks. Angles of ordinary dots receive up to ±0.06 radians of deterministic jitter for legibility. | Give both denominators, describe angle as Z plus display jitter for dots. |
| Tests / About | Input grades are 290 E, 847 S, 2,518 T. wall sides are computations on those inputs. The v1 Lean declaration window_silver_silicon certifies the two sides for the encoded silver/silicon values. The independent scan establishes that these rows are the extrema; rounded endpoints are approximate. The v1 file lean/TwoFaceForms.lean proves equality of the rules at the wall and provides a midpoint counterexample. It supplies no universal off-wall uniqueness theorem. | Distinguish archive scan, exact endpoint certificate and full theorem. Say “of these two specified continuations.” If a later general certificate exists, link the exact declaration and pin. |
| Optical | The visible reflectance mean threshold classifies this selected 41-row sample. Its observable is reflected optical power; the underlying isolated-atom peel reflection is a different observable. The v1 code contains no transport response. | Use “same numerical half threshold” and retain the sample denominator. A transport claim requires its own observable and test. |

**Runtime and reproducibility.** Executed the original inline JavaScript with Node and linkedom 0.18.12, supplied the committed JSON through its fetch entry point, navigated all nine view routes, executed standard tile handlers and close handlers on every drawer. All nine routes set the correct visible view and selected nav link. Standard and signature each render 85 tiles. All 85 drawers opened and closed. The disk created 3,640 circles including its five guides. Native headless Chromium could not start because the execution host denies its process-singleton socket. That run did not validate pixel rendering, focus, or a live WebGL context. Independently inspected the native Three.js scale expression above. Missing Three.js returns silently from the 3D routine. The original builder and screenshot script use absolute /home/claude paths for the data, index and Three.js assets, and the screenshot script collects errors without asserting the result. The shipped HTML loads a sibling JSON file and Three.js from a CDN.
